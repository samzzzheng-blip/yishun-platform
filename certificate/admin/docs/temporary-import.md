# 临时区文件导入

入口：临时页面 → 导入临时商品。仅具有评级编辑权限的已启用账号可导入；数据归属由服务端登录会话决定。

## 文件规则

- 支持 XLS、XLSX、XML，单文件最多20MB、5000条。
- 支持标签、表面、居中、边缘、角落、总分、照片/图片、备注表头。
- 编号可以为空；编号及二维码文件名不生成正式证书，不写入正式评级表。
- 多行标签完整保留为信息汇总，名称取第二个非空行（只有一行则保留该行）。
- 评分可为空；填写时必须为0至10之间、间隔0.5的数字。
- 图片支持嵌入图片、数据URI及受支持的图片地址；单纯本地文件名不等于已上传图片。
- 每次有新记录的导入自动创建批次，序号从1开始，完成时间使用导入时间。

## 失败与重试

服务端在事务中导入，新记录任一校验或保存失败则本次新记录全部回滚，新存储的私有图片随事务回滚清理。

同一账号再次提交字节内容完全相同的文件会跳过仍在临时区的已导入记录。修改过的文件不保证去重；清除记录后可以重新导入。网络错误时先刷新列表核对结果。

## 实现与验证

接口：`POST /api/usr/gradingTemporaryImport`，multipart字段 `file`。

页面复用现有 Ant Design 弹窗、上传与结果提示，不替换整体视觉系统。

后端测试 `GradingTemporaryImportTest` 覆盖空编号100条、账号隔离、重复提交、XLSX/XML、整批回滚、图片回滚、永久清除后再导入及实际XLS附件。全部工作流测试共78项通过。

前端 `scripts/temporary-import-smoke.cjs` 仅允许本机测试地址，覆盖移动端上传、结果展示、完成后刷新与重复文件跳过。生产构建通过。

当前为本地实现与隔离环境验证；没有部署，也没有把附件导入生产数据。
