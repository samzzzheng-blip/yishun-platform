# 卡片信息模板界面说明

## 范围

此功能是原评级工作台的局部扩展，保留现有蓝色、白色、深蓝后台视觉和 Ant Design 3 表单控件。模板管理以内联区域展开，卡片字段嵌入已有详情表单，不新增独立路由或视觉身份。既有 `DESIGN.md` 与 `.impeccable/design.json` 继续作为原设计依据；本文只记录本功能的界面与交互事实。业务约束见 `PRODUCT.md`。

## 布局

模板管理使用白底描边容器，最大宽度为 1000px，常规内边距为 20px。每个字段一行，依次呈现字段名称、字段后连接方式及排序和移除操作；空间不足时自然换行。模板选择与应用按钮同样支持换行。

卡片信息字段在宽屏为两列；视口不超过 640px 时改为单列，模板管理内边距调整为 16px，字段操作和应用按钮至少高 44px。选择模板后，字段直接替换原有固定卡片信息表单，收卡批次独立保留；未选择模板时继续显示原有字段。不存在独立的“打印标签信息”区域，打印仍使用原有格式。

## 组件与状态

- 当前模板后显示“切换模板”，展开候选列表并支持取消。候选模板显示只读字段预览和未应用提示；取消后恢复已应用字段，不丢失未保存值。
- “应用模板”打开范围选择，明确提供“仅当前卡片”和“同批次一键应用”，成功后解锁填写；无批次时禁用后者。弹窗说明批次应用会覆盖未确认卡片的单卡模板、不会复制内容，也不会修改已确认记录。请求期间禁止重复操作，错误保留在弹窗内，可取消或重试。

- 所有有评级查看权限且已启用的员工均可通过“管理卡片信息模板”展开编辑器；修改未保存时禁止收起，切换模板或新建会提示放弃未保存内容。
- 名称字段固定保留，名称输入和移除按钮禁用，但允许通过上移、下移按钮调整位置。首行上移、末行下移禁用；排序按钮提供可读的辅助标签。
- 每个字段使用“空格／换行”下拉框指定后续连接方式。末尾字段的连接方式不参与拼接。添加字段沿用普通按钮，保存模板为主按钮；保存中禁用编辑并显示加载状态，错误就地显示。
- 结构预览以占位文字展示当前顺序与换行。卡片详情中的文字预览使用实际字段内容，保留换行、跳过空值，并允许长文本折行。预览沿用正文字体、浅灰底和边框，不模拟新的品牌标签样式。
- 模板编辑器中的“名称”字段定义不可改名或删除，但卡片表单里的名称值可以填写，直接保存为原卡片名称。应用模板前如有未保存信息，按钮禁用并给出保存提示。应用动作使用现有确认弹窗说明影响范围；不可编辑记录保持只读展示。空格与换行仅控制卡片信息汇总，不影响打印格式。
