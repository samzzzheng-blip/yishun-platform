- 收藏系统三部分来自 Mac 的“一瞬收藏”工作目录，包含 2026-09-23 整理时未提交的源文件。
- 证书系统三部分来自移动硬盘 `yishun/yishun-master`、`yishun/react-master`、`yishun/yishun-mini`。

## 生产与源码的边界

一口价图片排序于 2026-09-23 部署，镜像标签 `yudao-server:20260923-image-order`。部署以线上原始 JAR 为基线，只替换四个排序相关 class，保留其他类和配置。新静态后台已部署。

小程序拍卖文案“拍卖结束，结果待工作人员确认”已上传微信开发版本 `2026.09.23.2`；上传不等于审核通过或正式发布。

归档中 `collection/miniapp/pages/index/index.vue` 与 `pages/index/user.vue` 还有本地修改，其发布状态未确认。本次归档不会替用户发布小程序。

### 签名证书／评级系统

源目录中存在较多本地开发功能；生产曾采用补丁部署，而非整体替换源码构建结果。归档的源码不能标为“与线上 JAR 一字不差”。

现有补丁目录覆盖：2026-09-11 的兼容／导入工作、2026-09-14 临时导入、2026-09-18 宝贝管理与评级／卡通查询、2026-09-23 Excel 导入和 WPS 相关修改。各目录是历史工作材料，存在依赖旧目录和线上基线的脚本，不是连续一键升级流程。

本次排除 baseline JAR、class、生成后的压缩 JS、安装 ZIP 等产物；补丁重现须先获得匹配的受保护基线，核对脚本所需输入路径与哈希。不能在未知版本上直接重跑。

`certificate/backend/docs/photo-retention-hotfix-20260914.md` 是当时的局部修复说明，其中“尚未部署”属于历史状态，不代表已核实当前生产状态。缺失照片不会由重新构建代码恢复。

## 排除与脱敏

不包含 node_modules、target、dist、unpackage、日志、用户媒体、数据库备份、私钥、Redis dump、测试请求中的登录凭据以及旧 Git 历史。第三方随源码分发的前端组件和界面素材保留。

- `sanitized-files.json`：自动替换敏感值的文件清单。
- `sql-data-exclusions.json`：去除数据写入语句的 SQL 清单。保留结构及菜单／字典种子；其他 INSERT 已去除，因此初始化后的角色、用户和业务数据须按受保护备份恢复或重新初始化。
- 原有 SQL 中仍可能包含 DROP/ALTER/UPDATE，不得批量对现网执行。应逐项审核，在空数据库验证。
