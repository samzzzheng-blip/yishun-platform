# 宝贝管理 Excel 导入调整

仅修改宝贝管理，不修改评级、赛璐璐、临时模块。已于 2026-09-23 部署，详见部署记录.md。

第一张工作表第一行为表头：证书编号、照片、签名人、载体、卡品、活动地址、活动时间、亲笔签名、证据图片、证据视频、评级、备注。

- 仅证书编号必填，其余为空时仍可导入。编号列按文本填写，保留前导零。
- 照片、证据图片支持 http(s) 或 /upload/ 地址，或对应单元格内锚定的 Excel 浮动图片（PNG/JPG/GIF）。不自动下载远程地址。
- WPS DISPIMG 单元格图片支持已于 2026-09-23 部署。仅从 .xlsx 内嵌资源读取照片、证据图片，不访问外部图片链接；缺失资源会报错，不会静默丢图。
- 证据视频可填写网络地址或本地文件路径，不导入 Excel 内嵌视频；不会自动生成视频封面。
- 本地附件流程：选择 Excel → 选择包含附件的文件夹 → 检查附件匹配 → 核对清单 → 确认导入。支持照片、证据图片、证据视频三列。
- 文件夹在浏览器本地建立清单，仅发送 Excel 引用并匹配到的文件；服务器从不尝试读取 C 盘等客户端路径。
- 优先匹配相对路径，无法匹配时仅接受唯一同名文件；匹配失败或冲突会阻止提交，需修正表格路径或重新选择目录。
- 每批 Excel 和引用附件总计 ≤90MB，照片每张 ≤10MB、视频每个 ≤80MB。视频格式 MP4/MOV/WebM/M4V。保留原有全局上传配置。
- 同一文件或系统内重复编号跳过，不覆盖旧记录/旧照片。保留原导入默认“未上架”状态。
- 每个文件不超过 20MB、5000 行；单张嵌入图片不超过 10MB。格式或长度不合要求的行会显示原因。
- 导入反馈显示成功/跳过数量及前 100 条错误。数据库保存失败时不删除已保存的独立图片文件，防止误删。
